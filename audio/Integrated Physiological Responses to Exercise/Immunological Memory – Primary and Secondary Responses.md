## Immunological Memory – Primary and Secondary Responses

Immunological memory is the third R of adaptive immunity.
It means that a second response to the same antigen is more rapid, larger and better able to eliminate it.
In the antibody response, this is the work of memory B cells.
The primary response takes five to ten days, with a low antibody titre, or concentration.
Its antibody is mainly immunoglobulin M, or I G M.
The secondary response takes one to three days, with a much higher titre.
Its antibody is mainly immunoglobulin G, or I G G.
That antibody also fits the antigen better, thanks to a process called affinity maturation.
Memory is specific to the antigen already met, which is why vaccination works.
In what follows, we'll see why the second time is different, compare the primary and secondary responses, and walk through one example of memory at work.

## 1. Why the second time is different

The third R is Remember, and it means that in a second encounter with an antigen, memory B cells produce a different antibody response.
On second exposure to the same antigen, the secondary response is more rapid, larger and better able to eliminate the antigen than the primary response to the first exposure.
So where does the difference come from?
Clonal expansion in the first response leaves behind memory B cells.
These far outnumber the few naive B cells that began it.
A naive B cell is one that has never before been exposed to antigen.
The memory cells are already selected and ready.
As a result, there is no long wait for a rare matching cell to find the antigen and multiply.
T cells remember in the same way, since clonal selection occurs for both T and B cells.
A T cell that recognises its antigen divides into two kinds of cell.
Effector cells fight the current infection and then mostly die, while memory T cells survive for the next one.
On a second exposure, memory helper T cells and memory cytotoxic T cells also respond faster and in larger numbers.
Helper T cells release cytokines that boost B cells, macrophages and other T cells, and cytotoxic T cells kill infected cells.
Even so, the slides on this topic show only B cells.
That's because they measure the response as antibody in the blood, and T cells make no antibody.
T cell memory is real, then, but it doesn't show up on graphs of antibody.

## 2. The primary response

Now for the primary response, which is the adaptive response to the first exposure to an antigen.
It is mounted by naive B cells, and only a few of them can recognise any one antigen.
Relying on so few cells, the response is slow and small.
Antibody takes five to ten days to appear, and it reaches only a low antibody titre.
The titre is the concentration of antibody in the blood.
It is measured as how far the serum can be diluted and still show antibody.
At this stage the antibody is mainly I G M, the first antibody made against a new infection.

## 3. The secondary response

The secondary response, by contrast, is the adaptive response to a second or later exposure to the same antigen.
It is mounted by the memory B cells left behind by the primary response.
Antibody now appears within one to three days, reaches a much higher titre, and is mainly I G G.
The move from I G M to I G G is called class switching.
In class switching, the B cell keeps its antigen specificity but changes the constant region of its heavy chain, which is the part that sets the isotype.
Secondary antibody tends to be more specific as well, meaning it fits its antigen more closely.
Its affinity is therefore higher, affinity being how tightly an antibody binds its antigen.
This comes from affinity maturation.
As B cells divide, small random changes in their variable-region genes make some antibodies fit better.
The B cells whose antibodies fit best are selected to expand.
In this way, the average antibody fits the antigen better than before.

## 4. Reading the memory figure

Imagine tracking the antibody response over time after immunisation, that is, after giving the antigen.
First, antigen X is given.
Naive anti-X B cells mount a small, slow primary anti-X response.
This leaves behind plasma cells, which secrete antibody, and memory B cells.
Later, X is given again, together with a new antigen, Y.
This time the anti-X response is fast and large, giving a secondary anti-X peak, because memory cells respond.
Y, on the other hand, has never been seen before, so it gets only a small primary anti-Y response from naive anti-Y cells.
The lesson is that memory is specific to the antigen already met.
Specific memory is the principle behind vaccination.
A vaccine is a first, controlled exposure to an antigen, so that the real infection meets a secondary response.
Beyond vaccines, memory is why adaptive immunity develops throughout a lifetime and improves with each contact with antigen.
In this respect, it differs from innate immunity.

## Summary

Pulling the threads together, memory B cells left by the first response are numerous and ready.
A second exposure to the same antigen therefore gives a response that is more rapid, larger and better able to eliminate the antigen.
The primary response takes five to ten days, with a low titre and mainly I G M.
The secondary takes one to three days, with a much higher titre and mainly I G G, after class switching.
On top of that, secondary antibody tends to be more specific, through affinity maturation.
Finally, memory is specific to the antigen already met, and that is the basis of vaccination.
Those are the two responses, and the memory that links them.
